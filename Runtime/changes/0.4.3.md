# Runtime Change: 0.4.3 — Two-ended relay policy and log retention

Version: 0.4.3

> [English](0.4.3.md) | [简体中文](0.4.3.zh.md)

## Problem

Relay changes need agreement between endpoints; retained logs need a configurable lifetime.

## Recorded changes

<a id="patch-9"></a>
### Patch 9

0.4.3 makes manual pSp a two-ended session policy. Either endpoint notifies the other through the friend synchronization channel when enabling or cancelling it; the operation completes only after the peer acknowledges application. Synchronization failure rolls back the local switch to avoid one-way relay.

<a id="patch-10"></a>
### Patch 10

0.4.3 adds log retention settings of 7/30/90/180 days or forever. Expired logs are checked immediately at startup and every six hours.
