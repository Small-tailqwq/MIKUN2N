# Runtime Change: 0.5.8-8 — 经同意的单跳好友协助

Version: 0.5.8-8

> [English](0.5.8-8.md) | [简体中文](0.5.8-8.zh.md)

## 问题

直连路径也可能不适合游戏，小型中继服务器的带宽又有限。

## 改动记录

<a id="patch-52"></a>
### 补丁 52

0.5.8-8：为选定 peer 对加入主动启用、单跳的好友协助。已有直连也可能不适合游戏，而全部流量经小型服务器中继又受带宽限制。客户端按需共享近期探测往返质量，请求者选择好友，由好友对每一对连接独立同意。原生接收准备先于路由激活。带租约的线路经验证过的 IPv4／IPv6 两段转发，保留原始 n3n 包和 peer 身份，不再经其他协助者或 supernode 转发。路径挑战、重复抑制、端点绑定和保温的原有 IPv4 路由支持不改变 TAP 地址的回退。IPv6 段保留尺寸发现与分片，TAP 与转发线程间的分片 ID 为原子操作。管理接口通告 peer_assist_version=1，提供 set_peer_assist 和 get_peer_assists。IPv6 保持第 3 代，不提供用户带宽配额设置。已有 IPv6／wire 离线回归通过，三方传输、游戏连续性和两种界面主题仍需实机验收。
