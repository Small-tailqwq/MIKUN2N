# Runtime Change: 0.5.8-1 — 暴露实际构建与线协议身份

Version: 0.5.8-1

> [English](0.5.8-1.md) | [简体中文](0.5.8-1.zh.md)

## 问题

混合线协议版本测试中，好友行无法识别不兼容的端点。

## 改动记录

<a id="patch-46"></a>
### 补丁 46

0.5.8-1：显示实际运行的原生构建与 IPv6 线协议代次。混合版本复测反复报告 remote=1/local=2，但好友行无法识别不兼容的是哪一端。QUERY_PEER 增加可选且有界的身份后缀，报告编译时构建标识和线协议代次；supernode 仅为匹配的已注册发送者保存，并通过 PEER_INFO 返回给支持的客户端。已有字段及旧读取端保留布局。版本文本检查长度和字符，缺失元数据保持未知；观察到的 IPv6 控制包也报告对端代次。get_info 暴露 mikun2n_build_version/ipv6_wire_version，get_edges 在 version 和 peer_ipv6_wire_version 中暴露对端构建与代次。此改动只增加元数据，不改变 IPv6 DATA 线协议版本 2，包构建号不同但协议兼容时仍可通信。客户端版本与实际 edge 构建分开显示，手动替换 Runtime 后也如此。原生发布标识在编译前由客户端 BaseVersion/BuildNumber 生成。
