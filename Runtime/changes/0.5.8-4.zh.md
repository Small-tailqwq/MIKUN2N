# Runtime Change: 0.5.8-4 — 保留已接纳重组并核对源码字节

Version: 0.5.8-4

> [English](0.5.8-4.md) | [简体中文](0.5.8-4.zh.md)

## 问题

未分片流量推进 ID 越过活跃重组，分发源码也需要与受跟踪工作树逐字节对应。

## 改动记录

<a id="patch-49"></a>
### 补丁 49

0.5.8-4：后续流量推进重放窗口时保留已接纳分片。仅为分片发送分配数据报 ID，包括 EMSGSIZE 后转为分片的 DATA；1200 次未分片发送不再消耗 ID。全局 ID 跳变前已接纳的重组保留固定两秒截止时间，完成／过期 ID 仍不能重开槽位。分配失败输出限频警告，第 3 代协议不变。对应源码直接从受 Git 跟踪的原生工作树导出，排除生成的配置和构建产物。逐项比对归档条目与源码字节，并扫描解压内容中的个人路径；验证报告记录实际不匹配和每个文件的哈希。
