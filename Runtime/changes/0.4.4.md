# Runtime Change: 0.4.4 — Report actual relay-policy matches

Version: 0.4.4

> [English](0.4.4.md) | [简体中文](0.4.4.zh.md)

## Problem

An unconditional success count cannot distinguish a recorded relay policy from an applied one.

## Recorded changes

<a id="patch-11"></a>
### Patch 11

0.4.4 makes set_peer_relay return the actual number of matching peer entries instead of always returning 1. The client can distinguish a recorded policy from an applied policy.
