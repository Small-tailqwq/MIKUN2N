# Runtime Change: 0.4.1 — Complementary NAT4 roles

Version: 0.4.1

> [English](0.4.1.md) | [简体中文](0.4.1.zh.md)

## Problem

Dual-NAT4 peers need complementary scanning and anchoring behavior.

## Recorded changes

<a id="patch-6"></a>
### Patch 6

0.4.1 assigns complementary scanner/anchor roles by the peers' MAC addresses for dual NAT4. The scanner uses shared wall-clock slices; the anchor repeats a fixed destination to stabilize its mapping. Exclude supernode endpoints accidentally admitted to pending_peers. get_edges additionally reports punch_role and the current band.
