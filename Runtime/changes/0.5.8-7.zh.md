# Runtime Change: 0.5.8-7 — 普通构建的 NAT66 发现

Version: 0.5.8-7

> [English](0.5.8-7.md) | [简体中文](0.5.8-7.zh.md)

## 问题

普通构建无法通过仅供私有测试的观察者配置发现公网 NAT66 映射。

## 改动记录

<a id="patch-51"></a>
### 补丁 51

0.5.8-7：让普通构建发现 NAT66 映射，同时不开放无条件 STUN。NAT66 后的 edge 曾通告其他 peer 不可达的私有 ULA，且只有私有测试构建能指定 STUN 观察者。启动器可在 MIKUN2N_IPV6_STUN_SERVERS 中传入带 “m:” 前缀的观察者，即 supernode 自带的 supernode/mikun2n-stun.py。edge 向它发送带 SOFTWARE 属性 “MikuN2N/1 <device MAC>” 的 Binding 请求，填充至 48 字节，使 44 字节应答不会放大伪造来源流量；观察者只回答当前在该 supernode 注册的 MAC。无前缀观察者（公共回退）仍只收到匿名 20 字节请求，不向第三方发送标识。顺序与故障切换不变，第一个超时后才使用第二个。请求格式不影响 peer，线协议仍为第 3 代，与 0.5.8-5 peer 互通。离线回归检查带标识字节与匿名回退请求。
