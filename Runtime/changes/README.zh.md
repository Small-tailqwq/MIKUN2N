## 阅读说明

日志描述所标版本的行为与测试结果。了解当前行为时，请结合最新的相关记录和技术文档。

编号改动 1–55 使用稳定的 `patch-N` 锚点，供其他文档引用。第 1–5、34–37 项的版本未知，集中放在[未标版本记录](unversioned.zh.md)中。每项编号记录用两种语言说明实现和测试结果。

## 维护方式

每个新版本新增一组英文／中文文件，在该版交付过程中持续更新。记录问题、改动、兼容影响和测试结果，有待验证的项目写在相关内容旁。改变以前的设计时链接旧记录。两边的语言跳转与标题层级保持对应。

改动详情放在版本文件中，按需更新此处的主题链接。这些 Markdown 文件随构建与发布分发，发布脚本会检查它们是否齐全。

修改时核对两种语言、本地链接及随包内容。源码打包步骤见 [BUILD.zh.md](../BUILD.zh.md)。
