# Runtime Change: 0.4.2 — Wide cone sweeps and relay control

Version: 0.4.2

> [English](0.4.2.md) | [简体中文](0.4.2.zh.md)

## Problem

Mixed NAT scenarios need wider coverage and per-peer manual relay control.

## Recorded changes

<a id="patch-7"></a>
### Patch 7

0.4.2 upgrades the NAT3/cone endpoint's layered strategy to a continuous wide sweep. Sixty-three consecutive batches cover peer control±1..4096 symmetrically without skipped positions, while repeated control traffic retains the stable mapping. This chiefly supports NAT3 against dual-bank NAT4.

<a id="patch-8"></a>
### Patch 8

0.4.2 adds set_peer_relay. A virtual IPv4 address can select a peer whose outgoing traffic is forced through the supernode and whose enhanced punching is paused. Cancelling resets its punching budget. get_edges reports forced_relay/force_relay.
