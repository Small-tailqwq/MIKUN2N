# Runtime Change: 0.5.8-2 — 方向性尺寸与有界分片

Version: 0.5.8-2

> [English](0.5.8-2.md) | [简体中文](0.5.8-2.zh.md)

## 问题

较小入站探测清掉较大已确认预算，使本可通过 IPv6 的 DATA 转为中继。

## 改动记录

<a id="patch-47"></a>
### 补丁 47

0.5.8-2：将方向性 IPv6 包尺寸发现与保活分离，并加入有界隧道分片，IPv6 线协议升为第 3 代。0.5.8-1 中，入站 1232 字节对端探测反复清掉已确认的 1418 字节路径，使 1383 字节封装 DATA 走 IPv4/pSp。基础保活独立于较大尺寸搜索；短确认把精确探测尺寸绑定到挑战、会话和端点。三次较大探测丢失将分包尺寸降到 1232，并退避较大尺寸搜索，不使基础路径失效。超大 n3n 数据报使用每个 peer 最多四个有界重组槽、固定两秒过期、范围／重叠检查和重复抑制。瞬时发送队列压力保留路径；部分发送不再经 IPv4 重放。同会话候选刷新保留已验证映射。第 1／2 代 peer 走 IPv4 兼容路径。原生诊断和管理接口暴露方向性限制与分片计数。离线测试覆盖尺寸、乱序、重复、过期、错误会话／端点及 socket 错误。
