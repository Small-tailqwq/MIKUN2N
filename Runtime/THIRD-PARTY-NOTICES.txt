MikuN2N third-party components
=========================================

MikuN2N itself (MikuN2N.exe) is free software licensed under GPL-3.0-only; the full
text is LICENSE.txt next to the program. Its source code is published in the project
repository, and every release is built from the tagged source tree. MikuN2N runs the
components below as separate programs or links them as runtime libraries; each keeps
its own license.

- License: GPL-3.0-only
- Upstream: https://github.com/n42n/n3n

- Upstream release date: 2024-12-07
- Windows Authenticode: not signed
- Bundled license: LICENSE-n2n.txt
- Bundled corresponding source: n3n-3.4.4-source.zip
- Source archive SHA-256: CF86CDD8E471205400583FF13F8684D09195E45BE7F228F46B44897F6AA4273E

3. .NET, WPF and Windows Forms

- Self-contained package: .NET 9 Windows runtime embedded in MikuN2N.exe
- Framework-dependent package: Microsoft apphost and application code only; the
  .NET 9 Desktop Runtime x64 is installed separately, not redistributed in this ZIP
- Packages: Microsoft.NETCore.App.Runtime.win-x64 and
  Microsoft.WindowsDesktop.App.Runtime.win-x64 (both MIT licensed)
- License: MIT
- Bundled license: LICENSE-dotnet.txt
- Bundled notices: THIRD-PARTY-NOTICES-dotnet.txt (components the runtime incorporates)
- Upstream: https://github.com/dotnet/runtime, https://github.com/dotnet/wpf,
  https://github.com/dotnet/winforms

MikuN2N does not add a third-party tray package. Its tray integration uses the
Windows Forms APIs included with the .NET Windows desktop runtime.

4. MinGW-w64 toolchain runtime (inside n3n-edge.exe)

- n3n-edge.exe is built with MinGW-w64 GCC and statically includes parts of libgcc and
  the MinGW-w64 C runtime startup code.
- libgcc: GPL-3.0 with the GCC Runtime Library Exception, which places no conditions
  on the compiled program.
- MinGW-w64 runtime: public domain and permissive licenses (see the mingw-w64
  COPYING files).
- It links dynamically against the Windows Universal C Runtime, a system component.

Not distributed

- A legacy n2n v3 edge.exe once used during development is not part of any package or
  of the source repository, because its corresponding source cannot be reproduced.
  MikuN2N still starts a user-supplied Runtime/edge.exe when n3n-edge.exe is absent.
