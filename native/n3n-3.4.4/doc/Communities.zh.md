# 小组（Community）

> [English](Communities.md) | [简体中文](Communities.zh.md)


## 名称

小组代表一个个虚拟网络，因此必须能互相区分。区分它们的就是名称，所以每个网络的名称都应当是唯一的。小组名称最多由 19 个单字节字符组成，后面再跟一个 NUL 结束字节，总长最多 20 字节。因此小组名称中永远不能包含 NUL 字节。另外还有一些字符不能使用，即 `. * + ? [ ] \`。

为了充分利用可用字符，也可以使用十六进制值，例如在 Linux 的 bash 中使用 `n3n-edge … -c $(echo -en '\x3a\x3b\x4a\x6a\xfa') …` 这样的命令行写法。如果使用配置文件，则必须把这些字节作为字符直接写进对应的 `community.name` 选项中。

除了命令行的 `-c` 和配置文件之外，还可以通过环境变量 `N3N_COMMUNITY` 提供小组名称。在启用了头部加密时（见下文），这样做可以避免小组名称出现在命令行里。


## 限制可以使用 Supernode 的小组

默认情况下，supernode 为所有小组提供服务，允许任何小组连接。如果希望自己搭建的 supernode 只服务特定的小组，可以给 supernode 提供一份允许的小组列表。这个列表是一个简单的文本文件，每行一个允许的小组名称：

```
 # community.list (a text file)
 -----------------------------------------------------
 myCommunity
 yourCommunity
```

这个文件通过 `supernode.community_file` 选项提供给 supernode。在这个例子中，supernode 只接受名为"myCommunity"和"yourCommunity"的小组连接，它们属于固定名称的小组。


## 稍微灵活一些的小组名称

如果想允许某一范围内的所有小组名称，例如从"myCommunity00"到"myCommunity99"，`community.list` 文件（或者你给它起的其他名字）可以这样写：

```
 # community.list (a text file)
 -----------------------------------------------------
 myCommunity[0-9][0-9]
```

熟悉的用户会认出这就是正则表达式。为了不把读者吓跑，作者没敢把这一节命名为"正则表达式"。总之，小组名称可以用正则表达式来写，支持以下占位符：

```
 '.'        点号，匹配任意字符
 '*'        星号，匹配前一个元素零次或多次（贪婪）
 '+'        加号，匹配前一个元素一次或多次（贪婪）
 '?'        问号，匹配零次或一次（非贪婪）
 '[abc]'    字符类，匹配 {'a', 'b', 'c'} 中的任意一个
 '[^abc]'   反向字符类，匹配不在 {'a', 'b', 'c'} 中的字符（该功能目前有缺陷）
 '[a-zA-Z]' 字符范围，即 { a-z | A-Z } 范围内的字符
 '\s'       空白字符：\t \f \r \n \v 和空格
 '\S'       非空白字符
 '\w'       字母数字，即 [a-zA-Z0-9_]
 '\W'       非字母数字
 '\d'       数字，即 [0-9]
 '\D'       非数字
```

了解这些之后，上面示例中的 `community.list` 也可以写成：

```
 # community.list (a text file)
 -----------------------------------------------------
 myCommunity\d\d
```

同时，由于 `. * + ? [ ] \` 这些字符是正则表达式的组成部分，现在也就明白为什么固定名称的小组不能使用它们了。


## 头部加密

默认情况下，每个数据包都以明文携带小组名称。所以，固定名称的小组或许能把你的弟弟妹妹挡在外面（只要他们不知道小组名称），但抓包的攻击者可以轻易得到小组名称，然后只要连上 supernode 就能进入这个小组。

启用[头部加密](Crypto.md#header)（英文）可以避免以明文传输。需要明白的是，头部加密只对固定名称的小组有效，对用正则表达式描述的小组名称不起作用。

另一方面，一旦提供了固定名称的小组列表，所有不在列表中的小组都会被拒绝。如果想同时允许某些加密的（因而是固定名称的）小组和其他所有开放小组，可以用下面这个"技巧"：

```
 # community.list (a text file)
 -----------------------------------------------------
 mySecretCom
 .*
```

这其实算不上什么技巧，只不过是在第二行用了一个非常宽松的正则表达式而已。
